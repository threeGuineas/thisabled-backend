# Q: 친구 추천 부분도 로딩이 안되는 문제가 있다고 하는데 확인 부탁함

## Answer

Expanded from original query via vocab: [recommendations, recommendation, match, model, candidate, pool, reasons, score, api, http, friend, users]. recommendations() builds a candidate_pool(), serializes user_features(), and calls MatchClient.score(). The live match-input-v2 server accepts the legacy tags wire field and the backend TAG-01 catalog matches its 43 allowed tags. The reproduced failure is ui_mode=default: backend UiMode permits default, while the AI MatchingInputPolicy allowed_ui_modes omits default, so any batch containing that user returns 422 INVALID_UI_MODE. MatchClient converts the HTTP error to MatchUnavailable and recommendations() responds HTTP 200 with items=[] and the temporary message; a live authenticated request reproduced this in 59 ms. Therefore recommendation generation is unavailable, and a frontend that does not terminate loading for empty items/message can appear stuck.
