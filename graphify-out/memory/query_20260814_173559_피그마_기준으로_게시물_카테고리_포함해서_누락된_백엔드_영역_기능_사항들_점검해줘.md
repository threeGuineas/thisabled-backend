# Q: 피그마 기준으로 게시물 카테고리 포함해서 누락된 백엔드 영역 기능 사항들 점검해줘

## Answer

Figma Page 1과 SSOT v2.2, 실제 FastAPI 모델·스키마·라우터·테스트를 대조했다. 게시물 카테고리 5종, 제목, 제목·본문 검색, 사용자별 게시물 목록과 프로필 활동 집계가 미구현이다. 채팅 목록은 안읽음 수는 구현됐지만 최근 메시지 미리보기·최근활동 정렬·검색·온라인 상태가 없다. 통화와 알림 설정은 Figma에는 보이나 SSOT 범위 밖이라 명세 결정이 필요하다. 기존 댓글 추천, 친구 추천, 피드 최신순, 게시물 CRUD, 미디어 접근성 처리, 읽음·안읽음은 구현돼 있다. 전체 테스트 122개 통과.
