# Q: post 필드에 원래 title 필드가 요구되지 않았던거같은데 왜이렇게 된거지?

## Answer

Expanded from original query via graph vocab: [post, title, publish, schema, request, category, draft]. 원래 v2.2 및 11ddf6f 이전 API는 content와 media_ids만 요구했고 title 필드는 없었다. 2026-08-15 commit 11ddf6f feat(posts): 카테고리·제목 검색 구현에서 카테고리 기능과 제목·본문 검색을 한 변경으로 묶으면서 PostCreateIn과 PublishIn의 title을 필수로 추가했고, 이후 v2.3 문서가 그 구현을 명세로 반영했다. 따라서 현재 422 Field required는 이 신규 필수 계약 때문에 발생하며 기존 계약에서 유래한 것이 아니다.
